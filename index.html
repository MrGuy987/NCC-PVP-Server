About this dashboard

This is a static GitHub Pages demo inspired by common game-server dashboards.

GitHub Pages serves files to visitors; it does not provide a process, filesystem API, or a secure server-control endpoint. Connect a separately hosted backend if you want these controls to affect a real server.

Demo changes are saved only in this browser using local storage.
